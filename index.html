Instalar como app

Cuando esta web esté publicada con HTTPS, Chrome o Safari permiten agregarla a la pantalla de inicio.

Si no aparece el botón de instalación, usa el menú del navegador → “Agregar a pantalla de inicio”.
Acerca de la privacidad

Esta versión usa Supabase Auth y PostgreSQL. Las contraseñas las gestiona Supabase Auth y los permisos de lectura/escritura se aplican también en la base de datos mediante Row Level Security (RLS).
